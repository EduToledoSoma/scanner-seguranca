=====================================================
scanner.sh
=====================================================

Hidden Admin Detection: Scan the `wp_users` table via WP-CLI to list administrators created recently or without your knowledge.

Recent Uploads Monitoring: List files created or modified inside `wp-content/` within the last 24 or 48 hours.

Critical Files Audit: Monitor structural changes to `.htaccess`, `robots.txt`, and `index.php`.

Malicious Redirects Scan: Test the site homepage using `curl` with mobile/Googlebot user-agents to reveal "spam redirects" that only show to visitors.

Extra Hidden/Temporary Files Detection: Search for forgotten backup files on the server such as `.zip`, `.tar.gz`, `.sql`, or `wp-config.php.bak`.

WordPress Cron Analysis: Scan scheduled cron jobs to check for suspicious tasks executing unknown scripts.

Database Table Malware Detection: Scan post tables (`wp_posts`) for invisible iFrames or spam links injected into old content.

=====================================================
remediador.sh (Ideas to Expand Fixes and Protections)
=====================================================

Pre-Fix Automatic Backup: Create a quick `.zip` of the site folder and an SQL dump before applying any invasive changes.

Reset Suspicious Admin Passwords: Force password reset or demote accounts that appear to be unauthorized admin creations.

Security-Only Automatic Updates (WP-CLI): Automatically update only Core, plugins, and themes that have critical security fixes pending.

Disable Directory Indexing: Add `Options -Indexes` to `.htaccess` to prevent attackers from browsing directory listings.

Remove Inactive Themes and Plugins: Automatically delete disabled plugins and themes (they are often attack vectors).
